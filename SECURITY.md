# Security

SubCellSeg is a research tool that runs locally and downloads one model file
from a GitHub release, verified by SHA256. It does not collect or send data.

If you find a security problem, for example in how files or URLs are handled,
please do not open a public issue. Email the maintainers at

weeks. Dependency vulnerabilities reported by GitHub are handled through
normal pull requests.
